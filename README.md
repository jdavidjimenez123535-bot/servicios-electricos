## Cómo Usar

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/jdavidjimenez123535-bot/servicios-electricos.git
   ```

2. **Abrir en navegador**
   - Simplemente abre el archivo `index.html` en tu navegador favorito
   - O despliega en GitHub Pages para acceso remoto

3. **Personalizar**
   - Edita los datos de contacto en `index.html` y `script.js`
   - Modifica colores en `styles.css` en las variables CSS
   - Actualiza información de servicios según tus necesidades
